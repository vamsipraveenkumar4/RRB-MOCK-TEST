# RRB MOCK TEST

A comprehensive Online Mock Test Application for RRB (Railway Recruitment Board) Examination Preparation built with React, Vite, and TailwindCSS.

## Features
- Exam Engine with Timer & Question Navigation
- Instant Score Calculation & Detailed Result Analysis
- Subject-wise Practice Tests & Question Paper Library
- Bookmarks & Incorrect Question Review
- PDF Import Support for Mock Test Papers

## Tech Stack
- **Frontend**: React 19, Vite
- **Styling**: TailwindCSS
- **Icons**: Lucide React
